# ملف الإنجاز الإلكتروني للمعلم

صفحة ملف إنجاز مرتبطة بقاعدة بيانات **MySQL** (تُدار من **phpMyAdmin**):

- **الزوار** يشاهدون جميع الأقسام والملفات **للقراءة فقط**.
- **المسؤول (الأدمن)** وحده يسجّل الدخول ويعدّل كل شيء: البيانات والصور والملفات والإعدادات.

## محتويات المجلد

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة نفسها |
| `api.php` | الوسيط بين الصفحة وقاعدة البيانات (يتحقق من صلاحية المسؤول قبل أي تعديل) |
| `config.php` | ✏️ **الملف الوحيد الذي تعدّله**: بيانات قاعدة البيانات وكلمة مرور المسؤول |
| `database.sql` | جداول قاعدة البيانات (للاستيراد من phpMyAdmin) |
| `uploads/` | تُحفظ فيه الصور وملفات Word وPDF المرفوعة |
| `.htaccess` | حماية ملفات الإعدادات ومنع تشغيل أي سكربت داخل `uploads` |

## خطوات التركيب على الاستضافة (cPanel)

1. **أنشئ قاعدة بيانات**
   من cPanel ← **MySQL® Databases**:
   - أنشئ قاعدة بيانات جديدة (مثلاً `portfolio`).
   - أنشئ مستخدماً بكلمة مرور قوية.
   - اربط المستخدم بالقاعدة وامنحه **ALL PRIVILEGES**.

2. **استورد الجداول**
   افتح **phpMyAdmin** ← اختر قاعدة البيانات من القائمة الجانبية ← تبويب **استيراد (Import)** ← اختر الملف `database.sql` ← **تنفيذ (Go)**.
   (إذا تخطيت هذه الخطوة سيُنشئ `api.php` الجداول تلقائياً عند أول تشغيل.)

3. **عدّل `config.php`**
   ```php
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'اسم قاعدة البيانات كاملاً');   // غالباً بالشكل: cpaneluser_portfolio
   define('DB_USER', 'اسم المستخدم كاملاً');          // غالباً بالشكل: cpaneluser_dbuser
   define('DB_PASS', 'كلمة مرور قاعدة البيانات');

   define('ADMIN_USERNAME', 'admin');                  // اسم دخول المسؤول
   define('ADMIN_PASSWORD', 'كلمة-مرور-قوية-هنا');      // لن يعمل الدخول ما دامت CHANGE_ME
   ```

4. **ارفع الملفات**
   من cPanel ← **File Manager** ← `public_html` (أو مجلد فرعي مثل `public_html/portfolio`) ← ارفع جميع محتويات هذا المجلد كما هي، بما فيها `uploads` وملفات `.htaccess`.
   تأكد أن مجلد `uploads` قابل للكتابة (الصلاحيات `755`).

5. **جرّب**
   - افتح رابط موقعك: ستظهر الصفحة للزوار للقراءة فقط.
   - اضغط أيقونة القفل 🔒 أعلى الصفحة (أو «دخول المسؤول» في الأسفل) وسجّل الدخول.
   - بعد الدخول تظهر أزرار التعديل والرفع و⚙️ الإعدادات، ويُحفظ كل تعديل تلقائياً (يظهر «محفوظ» أعلى الصفحة).

## الأمان

- كل عمليات الحفظ والرفع والحذف تُرفض من الخادم إن لم يكن المستخدم مسؤولاً مسجّل الدخول، حتى لو حاول أحد تجاوز الواجهة.
- طلبات التعديل محمية برمز CSRF، وملف تعريف الجلسة `HttpOnly` و`SameSite=Strict`.
- بعد 5 محاولات دخول خاطئة يُقفل الدخول من نفس الجهاز 15 دقيقة.
- يُقبل رفع الصور وWord وPDF فقط، مع التحقق من محتوى الملف، وتُحفظ بأسماء عشوائية.
- لمزيد من الأمان يمكنك وضع ناتج `password_hash('كلمتك', PASSWORD_DEFAULT)` (يبدأ بـ `$2y$`) بدلاً من كلمة المرور الصريحة في `config.php`.
- لا ترفع `config.php` بعد تعبئته إلى مستودع عام على GitHub.

## ملاحظات

- إذا فتحت `index.html` مباشرة من جهازك (بدون خادم PHP) تعمل الصفحة في **وضع تجريبي** وتُحفظ التعديلات في المتصفح فقط.
- حجم الرفع الأقصى يُضبط من `MAX_UPLOAD_MB` في `config.php`، ويجب ألا يتجاوز `upload_max_filesize` و`post_max_size` في إعدادات PHP بالاستضافة (cPanel ← **Select PHP Version** ← Options أو **MultiPHP INI Editor**).
- النسخ الاحتياطي: من ⚙️ الإعدادات ← أدوات ← **تصدير** (للبيانات)، ومن cPanel انسخ مجلد `uploads` (للملفات)، أو صدّر قاعدة البيانات من phpMyAdmin ← **تصدير (Export)**.
