# منصة المعلمة

منصة تعليمية لإدارة الطالبات بالعربي والإنجليزي: تسجيل الطالبات واعتمادهن، الأقسام والمحتوى، التسليمات وتقييمها، الحضور، المشاركة وورقة الرصد، لوحة التميز والشهادات، الجدول الأسبوعي، بوابة ولي الأمر، تواصل الأمهات عبر واتساب، النسخ الاحتياطي، والوضع الليلي.

| الملف | الوظيفة |
|---|---|
| `index.html` | الواجهة (الطالبة، المعلمة، ولي الأمر) |
| `style.css` | التصميم |
| `api.php` | الخادم: الدخول والبيانات ورفع الملفات |
| `config.php` | إعدادات قاعدة البيانات ورقم جوال المعلمة |
| `database.sql` | قاعدة البيانات كاملة في ملف واحد: الجداول + كل التحديثات (سجل العناصر المفتوحة، الجمهور حسب الفصل، ملف الإنجاز ومعاييره) |

## ملفات ناقصة

الواجهة تحتاج هذه الملفات، ولم تُرفع بعد:

- `script.js` — منطق الواجهة (بدونه لا تعمل الصفحة)
- `manifest.json` و`icon-192.png` و`apple-touch-icon.png` — تثبيت المنصة على الجوال

## التركيب (InfinityFree أو أي استضافة PHP + MySQL)

1. أنشئ قاعدة بيانات واستورد `database.sql` من phpMyAdmin.
   الملف آمن على قاعدة موجودة أيضاً: يضيف الناقص فقط ولا يحذف المحتوى.
   حساب المعلمة الجاهز برقم `0500000000`، وكلمة مروره لا تُكتب في المستودع لأنه عام.
2. ارفع الملفات إلى `htdocs`.
3. عدّل `config.php` **على الاستضافة** ببيانات قاعدة البيانات ورقم جوال المعلمة.
   المستودع عام، فلا ترفع البيانات الحقيقية إلى GitHub.
